# V4.6.0 · 桌面界面改版

- 左侧固定导航，统一 API 切换、Gemini 反代、本地网关、用量监控和环境设置的入口。
- 重新设计雾灰浅色和蓝灰深色主题，统一卡片、边框和输入框。
- 统一中文界面字体，增大正文与按钮字号，修正中文日志和提示字体。
- 主操作突出、辅助操作弱化；Gemini 服务操作移至模型额度上方。
- 默认窗口 1240 × 860，最小 1100 × 720，内容可滚动。
- 保留 V4.5.1 的 gcli2api 新版模型别名兼容、Gemini 3.8 Flash 动态发现与排序。

gcli2api 服务仍为独立安装组件。

- 新增双向切换图标，统一侧栏、窗口、任务栏和 EXE；ICO 包含 16 至 256 像素尺寸。
- 修正浅色选项文字对比度，Gemini 密码与模型输入改为分行。
- 编辑供应商的保存/取消操作固定在弹窗底部。

升级不会删除账号凭证或配置。EXE 未进行商业代码签名，Windows 可能提示未知发布者。
