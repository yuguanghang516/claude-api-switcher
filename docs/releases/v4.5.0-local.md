# Claude API Switcher V4.5.0 本地候选版

V4.5.0 是一次可靠性与使用舒适度更新。当前文件只记录本地候选版；通过完整验收前不创建 GitHub Release。

## 主要修复

- Claude 启动时清除父进程遗留的 Bedrock、Vertex 和 Foundry 选择器，避免界面已切换 Gemini/LongCat，实际会话仍走其他路由。
- gcli2api 额度查询改为受限并发，单凭证和整体均有时间预算；慢凭证不再让界面等待几十分钟，成功结果可以部分返回。
- gcli2api 启动并确认可调用后会自动刷新 Antigravity 额度，不再要求用户再点一次“刷新额度”。
- 额度刷新结束后会恢复常驻“可以调用”和下一步指引，不再把“正在刷新额度”永久留在状态栏。
- gcli2api 启停增加并发保护与精确进程身份校验；停止等待不再阻塞日志管道，启动超时只停止本次由软件创建的进程。
- gcli2api 子进程日志合并读取，最多保存最近 40 行、每行 500 字符，并脱敏 API 密码、面板密码、Authorization、Bearer Token 和 URL key 参数。
- Gemini 自动切换使用一次请求一个不可变配置快照，避免设置刷新时混用旧地址/密码和新模型。
- 合法 JSON 但结构错误的配置不再触发崩溃；损坏配置会先移动到带时间戳的备份，再恢复默认配置。普通读取权限或磁盘错误不会覆盖原文件。
- 旧 Provider ID 首次补齐后立即持久化；无密钥导出/导入现在保留并校验优先级。
- 更新检查只允许打开本项目的 HTTPS GitHub Release 页面。
- 增加 Windows 单实例保护，重复双击激活已有窗口，不再同时争抢配置、SQLite、7861 和 8787。

## 界面与交互

- 用量页路由开关读取真实配置，写入失败会恢复原状态并显示原因。
- 暗色次要文字提高对比度，正文和热力图辅助字号统一提升。
- 帮助提示使用当前主题颜色，扩大点击区域，处理屏幕四边边界，并支持 Escape/失焦关闭。
- Provider 编辑窗口支持小屏和高 DPI，自适应尺寸、可滚动、可调整大小；网关 Provider 编辑恢复真正模态行为。
- 主窗口切换语言后，用量面板及故障转移/通知动态状态同步更新。

## 发布质量护栏

- `scripts/check_version_consistency.py` 校验应用版本、PyInstaller 配置、Windows 文件信息和 README 一致。
- Windows CI 执行版本检查、源码编译、完整测试、PyInstaller 干净构建，并保存 EXE artifact。
- 代码签名和网关 SQLite 密钥迁移不在本版范围；两项都需要独立证书或兼容迁移方案，不能伪装成已经完成。
