# Claude API Switcher V4.1.0

V4.1 为 Windows 桌面版加入 gcli2api / Gemini 反代的完整可视化流程，并更新 Google Gemini 官方 OpenAI 兼容配置。

## 新增

- gcli2api 状态卡：安装、启动、服务检测、管理面板和 GitHub 项目入口。
- 缺少 Git 或 uv 时通过 WinGet 安装固定软件包；安装失败显示具体阶段和原因。
- 从 `/v1/models` 动态发现可用模型，优先选择 Pro 与 Flash 模型。
- 一键加入 Claude Code Provider 或本地 AI Gateway。
- Anthropic、OpenAI、Gemini 三种调用示例，复制内容只包含密码占位符。
- 中英文界面以及跟随系统、浅色、深色主题支持。

## 安全与边界

- gcli2api 是独立第三方项目，使用 CNC-1.0 非商业许可证，不包含在本项目 MIT 许可和 EXE 中。
- 安装器不执行网络返回的脚本文本，不修改 PowerShell ExecutionPolicy，不下载或上传 OAuth 凭据。
- 本地服务固定绑定 `127.0.0.1`；非本地 HTTP 地址会被拒绝。
- 携带密码的服务检测禁止跟随 HTTP 重定向，错误信息和复制示例不会暴露密码。
- 软件退出时只停止由本次软件进程启动且身份匹配的 gcli2api 进程。
