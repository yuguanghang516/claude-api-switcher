# Claude API Switcher V4.3.0

发布日期：2026-08-23（本地候选版本，尚未发布到 GitHub）

## 主要变化

- Gemini 反代新增 Antigravity 与企业 Gemini CLI 双模式，个人用户默认使用 Antigravity。
- 检测、Claude 供应商和本地网关均按模式自动填写正确端点、认证方式、模型与本地 API 密码。
- 现有 gcli2api 配置会原位迁移，避免重复供应商；403 会区分本地密码、Google 凭证和许可证问题。
- Gemini 反代页可直接多选导入 Antigravity 凭证 JSON，并自动刷新凭证、模型与额度。
- 新增逐模型额度列表；明确区分平台快照与真实调用状态，429 会显示额度耗尽和恢复时间，不再误报为超时。
- Antigravity 接入 Claude 时通过本软件 Anthropic 网关，真实 429 会优先切换到同系列可用文本模型，最多尝试 3 个模型；流式响应只允许在输出首字节前切换。
- 修复导入 JSON 后供应商测试固定在 15 秒误报超时：普通供应商仍为 15 秒，gcli2api 凭证验证和模型切换测试使用 90 秒并显示当前阶段。
- 已保存的“接入 Claude（自动切换）”配置会在软件重启后自动恢复 8787 本地网关。
- 本地 API 密码增加可见性按钮，操作步骤与提示文字统一为易读字号。
- 移除会误导为真实账单的成本控制、预算和自动低价模型切换。
- Claude Code 本机 Token 明确排除 Codex，正文 Token 与缓存 Token 分开，热力图只统计输入 + 输出。
- 网关日志增加粗粒度客户端来源，Claude 用量视图排除后续 Codex 调用。
- 环境设置增加版本、检查更新、GitHub、反馈、版本发布和更新日志入口。
- 应用版本与 EXE 文件名升级为 V4.3.0，继续使用原创蓝紫双向 API 路径图标。
