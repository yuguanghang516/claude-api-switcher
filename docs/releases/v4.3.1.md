# Claude API Switcher V4.3.1

发布日期：2026-08-28（正式版）

## 这次修复了什么

- Gemini 反代模型列表不再重复显示“假流式/”与“流式抗截断/”传输别名；同一真实模型只保留一项。
- 可调用文本模型按能力分层排列：Claude Opus/Sonnet、大参数 GPT、Gemini Pro/Thinking 优先，Flash/Lite 等模型随后显示。用户仍可手动选择任意可用模型。
- 额度列表每个模型新增“切换使用”按钮；当前模型明确标记为“当前使用”。
- 切换模型会同时更新 Claude 主模型、快速模型和 8787 自动切换网关的首选模型，并保存到本机配置。
- “API 切换”页的 Gemini“测试”和“测试并使用”现在会自动检查并启动 7861 gcli2api 与 8787 本地切换网关，不再要求用户先去另一个页面手动启动。
- 服务已经运行时只做健康检测，不重复启动进程。
- 未安装、未保存本地 API 密码、密码不匹配、OAuth/Antigravity 凭证未完成、没有可用模型或端口占用时，界面会显示对应原因和下一步操作。
- 旧配置中保存的传输别名会自动迁移为真实模型名。

## 用户怎么操作

1. 首次使用时，在“Gemini 反代”页完成安装、本地密码和面板登录。
2. 导入或登录 Antigravity 凭证后刷新额度。
3. 在额度列表中点击目标模型右侧的“切换使用”。
4. 回到“API 切换”页，直接点击 Gemini 供应商的“测试并使用”。软件会自动启动所需本地服务并验证调用。
5. 测试成功后选择项目目录，再点击“快速启动 Claude”。以后快速启动也会自动恢复所需服务。
