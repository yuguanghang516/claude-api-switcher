# Claude API Switcher V4.0.0

V4 把 Claude Code 安装环境、第三方 API 切换和本地 AI Gateway 放进同一个 Windows 桌面界面。最终用户可以直接下载单文件 EXE，不需要安装 Python。

## 主要变化

- 新增 Claude Code 自动检测、一键安装或更新、PATH 修复和 `claude doctor` 诊断。
- 优先通过 WinGet 安装；失败后尝试 Anthropic 官方 Windows 安装器。
- 下载失败时区分网络、代理、权限、超时、文件占用、包不可用和 PATH 未刷新等原因。
- 新增跟随 Windows、浅色、深色三种主题并持久化。
- 统一主界面、AI Gateway 和 V2 仪表板的颜色、字体、间距与状态反馈。
- 修复重复导航标签、供应商弹窗函数重名、版本号不一致和空 Key 模板误显示为可用的问题。
- V3 Web 默认仅本机监听，移除固定管理员密码，MCP Shell 默认关闭。

## 安装

下载 Release 附件：

```text
Claude API Switcher V4.exe
```

双击运行即可。首次启动的运行数据保存在：

```text
%LOCALAPPDATA%\ClaudeAPISwitcher
```

Claude Code 的 Windows 官方安装要求和安装器说明见：[Claude Code setup](https://code.claude.com/docs/en/setup)。

## 已知边界

- 当前主要面向 Windows 10/11。
- 独立 AI Gateway 的配置属于本机运行数据，不应提交到公开仓库。
- WinGet、代理或系统策略异常时，一键安装可能失败；界面会保留诊断输出和恢复建议。
