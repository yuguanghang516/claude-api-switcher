# Claude API Switcher V4.4.0（本地候选版）

此版本先交付本机检查，暂不上传 GitHub。

## 稳定性

- 自动检查项目内 `.claude/settings.json` 与 `settings.local.json` 的 API 路由污染，选择干净设置源；两个来源都冲突时明确拒绝启动。
- Gemini gcli2api 自动切换加入 45 秒单模型、90 秒整体时间预算，避免连续等待数分钟。
- 8787 本地切换网关配置在查询额度时自动解析到真正的 7861 gcli2api 面板。

## 界面与引导

- API 首页将当前使用的供应商置顶，已配置供应商优先于未配置占位项。
- 当前状态只保留一个统一说明入口，减少重复问号按钮。
- 当前供应商显示“当前使用 · 启动前自动检测”，避免把应用重启后的“未测试”误解成不可用。
- 用量页放大基础字号、增强暗色对比，为 7 天热力图增加强度图例。
- 增加“历史 Claude 模型用量”说明，明确 LongCat 等名称来自历史记录，不代表当前路由。
- Gemini 额度失败时引导到“Gemini 反代”页查看，不再只显示笼统的“不可用”。
