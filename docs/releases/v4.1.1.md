# Claude API Switcher V4.1.1

V4.1.1 修复 gcli2api 已经通过终端安装，却被软件误判为“未安装”并要求重复安装的问题。

## 修复

- 自动发现 `%USERPROFILE%\gcli2api` 等常见终端安装位置。
- 支持通过 `GCLI2API_HOME` 明确指定已有安装目录。
- 只有同时存在 `web.py`、`pyproject.toml` 和 `.venv\Scripts\python.exe` 才判定为完整可运行安装。
- 服务未启动时显示“已安装，未运行”，并展示实际安装路径。
- 启动按钮直接从检测到的现有安装目录启动服务。
- 检测到现有安装后，“一键安装”显示为“已安装”并禁用，不再诱导重复下载。
- 即使用户再次触发安装逻辑，也只返回“无需重复安装”，不会执行 WinGet、Git clone 或 `uv sync`。

## 验证

- 已在本机识别终端安装目录：`C:\Users\ygh\gcli2api`。
- 未运行服务时正确返回：`stopped / installed=True`。
- 自动化测试：327 项全部通过。
