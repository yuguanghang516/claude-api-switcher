# Claude API Switcher V4.3.2（本地候选版）

此版本仅在本机验证，按要求暂不上传 GitHub。

## 修复

- Gemini gcli2api 启动 Claude 时清除旧供应商的 Base URL、模型和认证变量。
- 每次通过全新的 Windows Terminal 窗口启动 Claude，并排除用户级 Claude 设置源，避免 `~/.claude/settings.json` 和旧标签页重新注入 LongCat 环境。
- 本地 8787 自动切换网关统一使用 Bearer 认证，不再同时设置两种 Anthropic 凭据。
- 当前供应商无效时停止启动，不再静默回退到列表中的 LongCat。
- gcli2api 测试改用完整 Anthropic 内容块和 64 个输出 token；HTTP 400 显示脱敏、限长的上游原因。
- Gemini 模型额度名称、状态和切换按钮统一使用微软雅黑字体。
