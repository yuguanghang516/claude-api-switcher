# Claude API Switcher V4.2.0

发布日期：2026-08-23（本地候选版本，尚未发布到 GitHub）

## 主要变化

- 修复已经从终端安装 gcli2api 后仍被误判为“未完整安装”的问题。
- gcli2api 增加安装、密码、启动、面板登录、Google OAuth、添加到 Claude 和测试使用的逐步指引。
- gcli2api 启动后等待 HTTP 服务实际响应，再显示成功；密码不一致、进程退出和超时均给出明确原因。
- 顶部导航重构为“API 切换 / Gemini 反代 / 本地网关 / 用量监控 / 环境设置”。
- 本地网关的“概览与模型 / 网关供应商 / 请求日志”改为二级分类，去除重复入口。
- “V2 智能”更名为“用量监控”，“额度与用量监控”更名为“用量与余额”。
- 用量页统一 16 / 13 / 11 的文字层级，移除结构性 emoji 和 9px 小正文。
- 增加近 7 天、按星期和小时统计的 Token 热力图，支持鼠标悬停查看精确用量。
- 增加 Claude Code 本机 Token、网关分供应商用量和官方余额三种严格分开的统计口径。
- LongCat 等没有公开余额接口的供应商不再显示伪余额，改为说明原因并提供平台入口。
- 增加原创蓝紫双向 API 路径图标，应用于窗口、任务栏和 EXE。
- 统一中文界面的“供应商”术语，移除残留的 Provider 开发文案。
