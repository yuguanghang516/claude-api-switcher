# gcli2api 配额查看、自动切换与凭证导入设计

## 目标

在“Gemini 反代”页完成三件事：用户可直接导入 Antigravity JSON 凭证；可查看每个模型的配额快照；通过本软件本地网关调用时，模型实测返回 429 `RESOURCE_EXHAUSTED` 后自动改用下一可用模型。

## 已确认事实

- gcli2api 面板使用 `POST /creds/upload?mode=antigravity` 导入凭证，字段名为 `files`，使用面板 Bearer 密码认证。
- `/creds/status` 与 `/creds/quota/{filename}?mode=antigravity` 提供凭证和逐模型配额快照。
- 配额快照可能显示 100%，真实消息请求仍可能返回 429。因此真实请求结果的优先级高于快照。
- Claude CLI 直接连接 gcli2api 时，桌面软件看不到请求，不能承诺自动切换。自动切换仅适用于 Claude/SDK 连接本软件网关的路径。

## 方案选择

采用“正式上传接口 + 网关实测故障转移”。不直接复制 JSON 到 gcli2api 数据目录，避免绕过 SQLite、远程存储及凭证刷新逻辑；不只依赖配额百分比选模型，避免 100% 快照与实际限流冲突；不在流式响应输出后切换模型，避免重复或损坏响应。

## 组件与数据流

### Gcli2ApiManager

- `import_credentials(paths, panel_password, mode)`：仅接受 `.json`，限制数量、单文件大小和总大小；本地先解析为 JSON 对象，不记录内容；multipart 调用 gcli2api 正式上传接口；把 400、401/403、连接失败和超时转换为用户可执行的中文提示。
- `get_model_quotas(panel_password, mode)`：读取已启用凭证，再读取每个凭证的模型配额，返回模型名、剩余比例、重置时间、凭证数和刷新时间。多个凭证同模型取最高剩余比例，同时保留可用凭证数。
- 所有请求不跟随重定向；远程地址必须是 HTTPS；日志不得包含密码、token、refresh_token 或 JSON 内容。

### 额度状态与候选排序

- 快照状态：正常、偏低、耗尽、未知。
- 实测状态：可用、429 冷却中、最近失败、未测试。
- 候选先排除冷却中的模型，再按剩余比例降序；同配额优先 Claude 兼容模型，其次 Pro，再次 Flash；用户当前选择的模型在健康时优先。
- 429 冷却为进程内状态，首次 60 秒、第二次 120 秒、第三次及以后 240 秒封顶；成功一次清除该模型冷却。重启不持久化。

### 自动切换路径

- 为本地网关增加 Anthropic `/v1/messages` 透传路径，供 Claude CLI 使用。
- 非流式请求可在收到 429/5xx/连接失败且尚未向客户端返回内容时切换候选，最多尝试三个不同模型；401/403、400、工具参数错误等不跨模型重试。
- 流式请求只允许在收到上游响应头且尚未输出任何数据前，因 429 切换候选；一旦向客户端输出首个 SSE 数据块，绝不中途切换。
- 响应增加内部日志和 UI 状态，明确记录“原模型 → 实际模型”和失败原因，但不改写上游正文。
- “一键接入 Claude（自动切换）”启动本地网关并把 Claude provider 指向网关；保留“直连 gcli2api”作为不支持自动切换的高级选项或调用示例，并明确标注差异。

## UI

- Gemini 反代页新增“导入 Antigravity JSON”按钮，旁边说明“支持多选；文件只发送到当前 gcli2api 服务”。导入完成弹出成功/失败数量并自动检测服务、刷新模型和额度。
- 新增紧凑的“模型额度”卡片：模型名、剩余进度、百分比、重置时间、实测状态；提供“刷新额度”。颜色不作为唯一状态信号，必须同时显示文字。
- 模型下拉框默认选择当前健康且配额最高的兼容模型；实测 429 后立即显示“冷却中”和倒计时，并显示自动切换目标。
- 额度区域明确提示：“配额为 Google/gcli2api 快照；若与真实调用冲突，以实测 429 为准。”

## 错误提示

- 429：显示当前模型额度耗尽、Google 返回的重置时间（若有）、已自动切换到的模型或“暂无可用候选”。
- 401/403：区分面板密码不匹配、API 密码不匹配和凭证无权限。
- 导入错误：按文件显示 JSON 语法错误、格式不支持、服务未启动、认证失败或 gcli2api 返回的安全摘要。
- 超时：仅在真实客户端超时异常时显示“超时”，不得把 429 显示成超时。
