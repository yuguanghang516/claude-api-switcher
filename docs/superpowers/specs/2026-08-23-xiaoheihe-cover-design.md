# 小黑盒宣传封面设计规格

## 目标

为 Claude API Switcher V4.3.0 制作一张适合小黑盒信息流展示的横版宣传封面。缩略图状态下首先读到主标题，其次识别软件蓝紫品牌图标和三项核心能力。

## 画布与安全区

- 输出格式：PNG
- 画布：1920 × 1080，16:9
- 关键文字和图标位于中央 80% 安全区，四周保留裁切空间
- 画面不得包含水印、二维码或无关品牌标识

## 文案

- 主标题：`一个软件，接管你的 Claude API`
- 副标题：`Claude · Gemini · LongCat｜一键配置 · 自动切换 · 用量监控`
- 标签：`V4.3.0`、`免费开源`
- 所有中文和英文必须逐字准确，不得生成近似字符或乱码

## 视觉方向

- 方向：深色赛博科技感的“能量核心”方案
- 背景：深黑到藏蓝渐变，加入克制的网格、粒子和蓝紫能量轨迹
- 构图：左侧为大标题和功能副标题，右侧为项目现有蓝紫 3D 双向 API 路径图标
- 品牌图标：使用 `assets/app_icon.png` 作为参考，保持双向箭头、蓝青到紫粉渐变、圆形节点和立体质感
- “Claude API”使用蓝青到紫色渐变强调，其余主标题为高对比白色
- 右侧图标周围用三条发光通路暗示 Claude、Gemini、LongCat 接入，但不使用第三方官方 Logo
- 标签使用小型玻璃拟态胶囊，避免抢夺主标题层级

## 质量要求

- 缩略到约 480 × 270 时主标题仍清晰可读
- 主标题是第一视觉层级，项目图标是第二视觉层级，副标题和标签是第三视觉层级
- 光效保持克制，文字区域背景足够干净，避免文字压在复杂纹理上
- 整体精致、可信，接近成熟 Windows 开源工具的正式发布视觉，不做廉价游戏广告风

## 交付

- 生成一张最终 PNG，并保存到 `assets/banners/xiaoheihe/v4.3.0-cover-1920x1080.png`
- 生成后检查尺寸、构图、文字准确性和品牌图标一致性；若文字存在错误，只针对文字和排版进行一次修正
